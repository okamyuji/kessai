# ADR-0014 管理画面の認証はセッションとArgon2idとする

## ステータス

Accepted（2026-08-11）

## コンテキスト

管理画面には返金というお金を動かす操作があり、認証・認可と監査証跡（誰が操作したか）が必須です。

## 決定

管理者アカウント（メールアドレスとパスワード）によるフォームログインとし、パスワードはArgon2idでハッシュ化します。セッションはサーバ側保存（DBのsessionsテーブル）でCookieはHttpOnly・Secure・SameSite=Laxとします。ロールは当面adminの1種類のみで、返金操作は操作者IDを監査ログに記録します。

## 根拠

htmx構成（ADR-0013）ではセッションCookieが最も自然で、トークン管理をブラウザ側に持ち込みません。Argon2idはOWASPが推奨する現行のパスワードハッシュです。

## 影響

CSRF対策（トークン埋め込み）を全POSTフォームに適用します。ログイン試行のレート制限を設けます。ロール追加（閲覧専用等）は要件が出た時点で行います。

## 検討した代替案

Basic認証は監査証跡（個人の識別）とログアウトの要件を満たせません。OAuth/OIDC（外部IdP）は学習範囲を広げすぎるため見送りました。
