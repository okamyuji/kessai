# ADR-0015 実行環境はローカルDocker Composeとする

## ステータス

Accepted（2026-08-11）

## コンテキスト

学習用途であり、クラウドデプロイは目的に含まれません。PostgreSQLとアプリの再現可能な起動手段が必要です。

## 決定

Docker Compose（アプリ、`postgres:18`）でローカル完結の構成とします。StripeのWebhook受信はStripe CLIのlistenコマンドでローカルへ転送します。シークレット（StripeのAPIキー等）は.envファイルで渡し、.gitignore対象とします。

## 根拠

追加費用ゼロで全機能（Webhook含む）を動かせます。Stripe CLIはサンドボックスのイベント転送を公式にサポートしています。

## 影響

クラウド固有の設計（マネージドDB、シークレットマネージャ）は行いません。本番化する場合の差分（TLS終端、シークレット管理、バックアップ）は03-basic-designの運用節に箇条書きで残します。

## 検討した代替案

ローカル直接実行（Composeなし）はPostgreSQLバージョンの再現性を欠きます。クラウドデプロイは費用と学習範囲の観点で見送りました。
